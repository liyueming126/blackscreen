# 午休息屏（blackscreen）

午休时间自动弹出全屏纯黑覆盖层（息屏效果），电脑不真正休眠（不休眠、不关显示器），到点自动恢复。给人看就像屏幕关了，实际上系统照常运行。

## 使用方法

1. 把 `午休息屏.exe` 复制到电脑任意位置（桌面、U盘、共享文件夹都行），双击运行
2. 程序驻留任务栏托盘：双击托盘图标或右键菜单可打开设置
3. 到达开始时间后 1 秒内自动息屏；息屏画面上单击鼠标或按任意键会短暂显示操作提示（默认关闭，可在设置里勾选开启）
4. 托盘右键菜单：
   - 启用午休息屏：总开关
   - 开机自启动：登录 Windows 时自动运行
   - 立即退出当前息屏：手动结束本次息屏
   - 测试息屏（5 秒）：立即演示效果（按 Esc 可提前结束）
   - 设置...：调整生效时段、日期、退出方式、息屏提示文字开关

## 默认设置

- 生效时间：12:10 - 13:10，每天（周一至周日）
- 退出方式（两种任选）：
  - 临时退出：息屏时按 Esc 或双击屏幕可退出，1 分钟后重新息屏
  - 退出后当天不再显示
- 息屏提示文字：默认关闭（纯净黑屏；可在设置里勾选开启，开启后息屏时短暂显示操作提示）

设置保存在 `config.ini`（与 exe 同目录）。如果 exe 放在不可写目录（如 Program Files）或网络共享路径（\\ 开头的共享、映射的网络盘），会自动改存到各用户自己的 `%LocalAppData%\NapScreenOff\config.ini`，首次运行会复制 exe 旁附带的 config.ini 作为个人初始设置，互不影响。

## 系统要求

- Windows 7 / 8 / 10 / 11
- 需已装 .NET Framework 4.x（Windows 10/11 自带）
- 多显示器、不同分辨率、不同缩放比例均自动适配

## 常见问题

- 息屏时屏幕还亮着？"息屏"是全屏纯黑覆盖效果，不会真正关闭显示器（有意设计：保证电脑继续运行、随时可退出）
- 息屏期间怎么操作电脑？按 Esc 或双击鼠标即可退出；开启过"提示文字"时，单击鼠标或按任意键会在屏幕上显示操作提示
- 到点后多久息屏/恢复？1 秒内自动切换，无需刷新或重启
- 改了 config.ini 不生效？手动编辑配置文件后需重启程序生效；用设置界面修改则立即生效

## 配置文件

`config.ini` 除用设置界面修改外，也可手动编辑（修改后需重启程序生效）：

| 键 | 含义 | 默认值 |
|---|---|---|
| `start` | 开始时间（HH:mm） | `12:10` |
| `end` | 结束时间（HH:mm），需晚于开始时间 | `13:10` |
| `enabled` | 是否启用息屏（true/false） | `true` |
| `policy` | 退出方式：`temp`=可临时退出（1 分钟后重新息屏）；`day`=退出后当天不再显示 | `temp` |
| `days` | 每周生效日，1=周一 … 7=周日，如 `12345` 表示仅工作日 | `1234567` |
| `hint` | `true`=息屏时在黑屏上显示操作提示文字；`false`=纯净黑屏 | `false` |

## 卸载

1. 托盘右键 → 取消勾选「开机自启动」
2. 托盘右键 → 退出
3. 删除 `午休息屏.exe` 和 `config.ini` 即可（若曾使用过 `%LocalAppData%\NapScreenOff` 目录，一并删除）
