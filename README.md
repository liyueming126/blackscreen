# 午休息屏（blackscreen）

午休时间自动弹出全屏纯黑覆盖层（息屏效果），电脑不真正休眠（不休眠、不关显示器），到点自动恢复。给人看就像屏幕关了，实际上系统照常运行。

## 使用方法

1. 把 `午休息屏.exe` 复制到电脑任意位置（桌面、U盘、共享文件夹都行），双击运行
2. 程序驻留任务栏托盘：双击托盘图标或右键菜单可打开设置
3. 托盘右键菜单：
   - 启用午休息屏：总开关
   - 开机自启动：登录 Windows 时自动运行
   - 立即退出当前息屏：手动结束本次息屏
   - 测试息屏（5 秒）：立即演示效果
   - 设置...：调整生效时段、日期、退出方式

## 默认设置

- 生效时间：12:10 - 13:10，每天（周一至周日）
- 退出方式：
  - 临时退出：息屏时按 Esc 或双击屏幕可退出，1 分钟后重新息屏
  - 强制锁定：息屏期间无法手动退出，只能等结束时间
  - 退出后当天不再显示

设置保存在 `config.ini`（与 exe 同目录）。如果 exe 放在不可写目录（如 Program Files、分享给他人挂在共享盘），会自动改存到各用户自己的 `%LocalAppData%\NapScreenOff`，互不影响。

## 系统要求

- Windows 7 / 8 / 10 / 11
- 需已装 .NET Framework 4.x（Windows 10/11 自带）
- 多显示器、不同分辨率、不同缩放比例均自动适配

## 常见问题

- 息屏时屏幕还亮着？这是息屏效果，不是真关显示器，Mac/其他软件场景下误以为关了是正常的
- 息屏期间怎么操作电脑？临时退出模式按 Esc / 双击鼠标即可
